# سازه‌یاب — backend

بک‌اند احراز هویت با Java 21، Spring Boot 3.5.7، Spring Security و MySQL 8.4.
کد فرانت ارسالی فقط برای بررسی قرارداد استفاده شده و داخل این مخزن کپی نشده است.

## اجرا

پیش‌نیاز: Java 21، Maven 3.9 و Docker Compose.

```bash
cd backend
# Set DB_PASSWORD and MYSQL_ROOT_PASSWORD securely in your shell/environment.
docker compose up -d --wait
mvn test
mvn spring-boot:run
```

متغیرها: `DB_URL` (پیش‌فرض دیتابیس محلی sazehyab)، `DB_USER` (پیش‌فرض sazehyab)،
`DB_PASSWORD` (اجباری)، `CORS_ORIGIN` (پیش‌فرض http://localhost:3000).
Flyway جداول را در اولین اجرا ایجاد می‌کند. رمزها و فایل `.env` را commit نکنید.

## API

| Method | Path | Body / result |
|---|---|---|
| POST | `/api/v1/auth/register` | `{ "name":"Ali", "phone":"09123456789", "password":"a-strong-password", "role":"client" }` → 201 |
| POST | `/api/v1/auth/login` | `{ "phone":"09123456789", "password":"a-strong-password" }` → 200 |
| GET | `/api/v1/auth/me` | اطلاعات کاربر؛ نیازمند Bearer |
| POST | `/api/v1/auth/logout` | ابطال نشست فعلی؛ نیازمند Bearer → 204 |

پاسخ ورود/ثبت‌نام: `{ "token":"…", "expiresAt":"…", "user":{"id":"…","name":"Ali","phone":"09123456789","role":"client"} }`.
در درخواست‌های محافظت‌شده، هدر `Authorization: Bearer <token>` ارسال شود.
نشست یک ساعت اعتبار دارد و خروج فوراً آن را باطل می‌کند. توکن تصادفی ۲۵۶بیتی است؛
فقط SHA-256 آن ذخیره می‌شود. رمزها با BCrypt هزینه ۱۲ ذخیره می‌شوند.
ثبت‌نام فقط `client` و `contractor` می‌پذیرد؛ دسترسی مدیر از ورودی کاربر ساخته نمی‌شود.
رمز ثبت‌نام حداقل ۸ و حداکثر ۶۴ کاراکتر و حداکثر ۷۲ بایت UTF-8 است.
شماره به صورت ۱۱ رقم انگلیسی و با 09 پذیرفته می‌شود.
خطاها: 400 ورودی نامعتبر، 401 احراز هویت نامعتبر، 409 شماره تکراری.

## اتصال فرانت و محدودیت‌ها

فرانت فعلاً mock است و در این تغییر به API وصل نشده است. در فرم‌های login/register
باید درخواست‌های بالا جایگزین mock شوند و `response.user` همراه `response.token`
به Redux داده شود. حداقل رمز فرانت نیز باید از ۶ به ۸ تغییر کند.
برای مرورگر توکن را در حافظه نگه دارید؛ نگهداری در localStorage در برابر XSS آسیب‌پذیر است.
هیچ حساب نمایشی یا مدیر پیش‌فرض وجود ندارد.

این نسخه تأیید مالکیت موبایل، پیامک OTP، بازیابی رمز و refresh token ندارد.
پیش از انتشار عمومی، HTTPS، محدودیت درخواست ورود/ثبت‌نام در gateway، مانیتورینگ و
سرویس تأیید پیامکی/بازیابی رمز لازم است. موفقیت ثبت‌نام به معنی تأیید شماره نیست.
تست‌های یکپارچه پیش‌فرض با H2 در حالت سازگار با MySQL اجرا می‌شوند؛ این جای تست MySQL واقعی را نمی‌گیرد.

محدودیت داخلی ورود/ثبت‌نام ۳۰ درخواست در دقیقه به ازای IP متصل است و در حافظه هر
نمونه نگه داشته می‌شود؛ پشت reverse proxy باید rate limit توزیع‌شده در gateway تنظیم شود.
این پیاده‌سازی به هدرهای قابل جعل X-Forwarded-For اعتماد نمی‌کند.

## اعتبارسنجی انجام‌شده

دو تست یکپارچه (بدون شکست یا skip) برای چرخه نشست، رمز اشتباه، شماره تکراری،
انقضا، جلوگیری از نقش مدیر و اعتبارسنجی ورودی اجرا شدند.
همچنین migration و ثبت‌نام پیمانکار، پروفایل، رد رمز اشتباه، خروج و ابطال توکن
با اجرای JAR روی MySQL 8.4 واقعی بررسی شدند.
